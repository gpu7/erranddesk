# Errand Desk

Plain, sourced answers for everyday US paperwork errands: where to go, what it costs, and what to ask before you drive over. Every figure links to its source and carries a "last checked" date.

Live site: https://erranddesk.com

Errand Desk is independent and is not affiliated with any government agency or with the businesses it lists.

## Repository

- `site-src/` is the source of truth for the site. See [site-src/README.md](site-src/README.md) for the build, page layout, fact rules and deploy steps.
- `erranddesk-site/` is the built output that gets deployed. Don't edit it by hand; rebuild from `site-src/`.

## Corrections

Email erranddesk@protonmail.com with the page URL and a link to the official source.
